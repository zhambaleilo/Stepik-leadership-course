# Roadmap сайта и продуктов My Pro Skills
Обновлено: 2026-10-14

## Продукты
P1. RPG-симулятор руководителя «Лаборатория лидеров» (флагман, play/).
P2. Курсы и SEO-контент (gost-45003.html, leadership.html, blog, статьи).
P3. Legacy-тренажёры (trainers/, translator-sbi, playground) — поддержка без развития.
P4. Портфолио автора для зарубежного рынка (resume.html, projects.html) — НОВЫЙ трек.

## Текущее состояние (готово)
- Игра: демо-режим (0 токенов), полная версия с GigaChat, динамический UI-триггеры,
  ИИ-судья по 11 критериям с цитатами, серверная нормализация баллов.
- Инфраструктура: GitHub Pages + Vercel api + Decap + Actions; golden-set и CI-регресс.
- Контент: 3+ статьи, курс ГОСТ 45003, шаблоны.

## Трек A — Игра (приоритет 1)
A1. Шаг 6: Supabase Free — реальные пароли доступа (таблица access_codes),
    сохранение диалогов и разборов, аналитика (средние баллы, флаг reused).
A2. Пакет из 3–5 сценариев через Decap (токсичный коллега, сопротивление изменениям,
    приоритеты и тайм-менеджмент) с осознанным набором 5–7 ключевых критериев.
A3. Полировка UI: перетаскиваемые окна, календарь/задачи как полноценные панели.
A4. Запуск на 100 тестировщиков, сбор фидбека, публикация кейса.

## Трек B — Английская версия под зарубежные вакансии (приоритет 2, старт СЕЙЧАС)
Мотивация: отклики на зарубежные вакансии → работодателю нужно портфолио на EN.
B1. EN-резюме: /en/resume.html (перевод + адаптация под международный формат, ATS-структура).
B2. EN-проекты: /en/projects.html с кейсом «Лаборатории лидеров» как главным артефактом.
B3. EN-демо игры: /en/play/ (перевод UI + EN-сценарий burnout_alexey_01_en + EN-библиотека
    критериев в evaluate.js). Демо самодостаточно и не привязано к ГОСТ-контексту.
B4. hreflang + переключатель RU/EN на переведённых страницах; EN-блок в sitemap.
НЕ переводим пока: статьи и курс (русское SEO, ГОСТ-контекст) — это отдельная стратегия под ISO 45003.

## Трек C — Гигиена репозитория (приоритет 3)
C1. Документация: README-карта и этот roadmap (готово этим коммитом).
C2. Консолидация ассетов: og-cover → img/, script.js → js/, styles.css → css/.
C3. Legacy: аудит playground/translator-sbi/data; мёртвое — в архивную папку с redirect-заглушками.
C4. Ревизия ссылок Stepik-курса перед любыми переносами.

## Трек D — Контент и SEO (приоритет 4, фоновый)
D1. Регулярность: 1 статья в 2 недели через Decap.
D2. Кейс-статья о «Лаборатории лидеров» после запуска на 100 тестировщиков.
D3. Микроразметка и OG-карточки для play/ (виральность демо).

## Принципы
1. Бесплатные тарифы до появления выручки; платное — только по триггеру роста.
2. Публичные URL неизменны; перенос = redirect-заглушка.
3. ИИ не арбитр: эталоны визирует человек, golden-set сторожит регресс.
4. Один продукт — один трек в работе; треки B и A не смешивать в одном коммите.
